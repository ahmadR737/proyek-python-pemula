# Proyek Python Pemula
Repositori ini dibuat untuk mengikuti materi dan praktikum Python dari SantriKoding.

## Daftar Materi
- variable_numbers.py: Latihan variabel angka

1. Pastikan Python sudah terinstal.
2. Jalankan file latihan dengan perintah: python3 nama_file.py
